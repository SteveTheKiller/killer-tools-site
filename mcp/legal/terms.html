KillerTools hosted service terms

Last updated: October 15, 2026

The service

Steve the Killer operates the hosted KillerTools utilities at mcp.killertools.net. The hosted connection provides calculations, conversions, formatting, public lookups, and reference catalogs. It does not control your computer, run generated PowerShell commands, or connect to installed Killer apps. Those capabilities require the installed Windows KillerMCP app.

Use and availability

Use the service only with information you are authorized to process. Do not bypass rate limits or access controls, disrupt the service, or use it for unlawful activity. Requests are limited to 64 KiB and tool-specific input limits. The shared limit is 120 requests per minute per connecting IP address. Availability also depends on Cloudflare and any external lookup provider needed for a call.

Review the results

The service is provided as available, without a guarantee of uninterrupted access or error-free results. Review generated commands before running them. Verify reference information and calculations before using them in a production or customer environment. A generated command or lookup result does not authorize a change to a system.
